## 当前入口与边界

- Console 的 `src/style.css` 加载 `@shop/design/console.css`。
- 基础样式进入 `base` 层，现有组件与兼容样式进入 `components` 层，新组件的 Tailwind 工具类进入 `utilities` 层；不让旧的全局按钮、字体和卡片规则盖住新组件的明确样式。
- 运行时色彩、字体、几何、密度的数值统一在 `src/console-theme.css`；`console-ui/tokens.ts` 只引用这些参数。
- 现有 `@shop/design` 组件 API 保留。现有业务页面通过 `--sw-*` 到 `--console-*` 的映射采用新视觉，查询、表单、路由、登录和权限逻辑沿用原实现。
- 导入组件从 `@shop/design/console` 单独导出，不覆盖同名旧业务组件的参数接口。
- `legacy-admin-theme.css`、`smart-wing-vi.css` 已停止被 Console 加载。旧品牌资料及其他应用的视觉入口不参与本次后台渲染。
- 桌面导入原型也同步了这套参数与正式 M 资产；其 `src/index.css` 加载 `src/design-system/console-theme.css`，3001 仍是独立原型预览，不能代表 LK 业务工程或线上 Console 的发布状态。
- 只更新后台。身份中心、商城、服务端、L-K 核心和节点契约不在本次迁移范围内。

## 字体、几何与密度

字体优先 Inter / Noto Sans SC，回退设备中文系统字体。金额和指标采用等宽数字；说明 12px、次级正文 13px、正文 14px、子标题 16px、区块标题 18px、页面标题 22px。

结构容器、控件和状态标签使用 2px 微直角，边框 1px；头像、单选框和状态圆点保持圆形。间距序列为 4、8、12、16、24、32、48px。卡片使用轻阴影，浮层使用独立阴影；常规按钮不使用渐变或悬停位移。

| 密度 | 表格行高 | 单元格纵向间距 | 控件高度 | 正文字号 |
| --- | --- | --- | --- | --- |
| 舒适 | 44px | 12px | 36px | 14px |
| 紧凑 | 32px | 6px | 30px | 13px |

主题与密度属于显示偏好，按当前浏览器保存。保存失败仍允许当前页面切换，不改变账号和业务状态。

## 布局与组件

顶栏跨全宽，显示正式品牌、真实业务范围、搜索、主题与密度、通知及真实账号。桌面导航宽 224px，折叠 64px，顶栏高 56px；业务区域保留已有路由标题、范围和统计周期。导航按经营、交易、生态、资金与用户、服务分组展示现有允许项，不创造原系统没有的入口。

迁入组件：BrandLogo、Button、Input、Select、Checkbox、Radio、StatusBadge、Tabs、MetricCard、DataTable、Modal、Drawer、Toolbar、Toast、CommandPalette。

- Button：主操作、次操作、描边、轻操作、异常操作，加载与禁用状态保持现有业务含义。
- Input / Select：标签、说明、错误提示与控件分别接语义色，输入数值和选择回调由调用页面负责。
- DataTable：表头、表体、选中、悬停、批量操作、分页、空数据和加载状态共用主题，实际数据及分页仍由业务接口提供。
- MetricCard / StatusBadge：数字、变化、状态和操作分别展示；视觉组件不编造指标或可用性结论。
- Modal / Drawer：头部、正文、底部、遮罩一同切换主题，保留关闭与提交行为。
- Toolbar / Tabs：筛选、搜索、刷新、页签和计数采用同一密度与交互色。
- Toast：成功、提示、警告、失败各自使用对应的状态色，文字随主题改变。
- CommandPalette：只消费调用方提供的真实命令和导航，不内置演示账号或业务操作。

宽度不超过 768px 时导航使用抽屉，表格允许横向浏览，顶栏按空间收起次要显示信息。键盘焦点使用交互蓝描边，减少动画偏好下去掉装饰过渡。
